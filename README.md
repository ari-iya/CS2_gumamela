# Distance Program

# # Description
This program calculates the distance between two points (x1, y1) and (x2, y2) on a 2d plane using input values and a math library.

# # How to run
1. Openthe program file in OnlineGBD.
2. Run the program.
3. Enter the values for x1, y1, x2, y2.
4. Check the distance displayed of the screen.

# # Inputs needed
- x1
- y1
- x2
- y2

# # Sample output
Enter x1: 2
Enter y1: 3
Enter x2: 7
Enter y2: 8
The distance between the two points is: 7.07
